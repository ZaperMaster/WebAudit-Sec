# WebAudit Sec

## Crear el ejecutable

En Windows 10 u 11, instala Python 3.10 o superior y Microsoft Edge WebView2 Runtime. Despues, ejecuta `build_windows.bat`.

El ejecutable se genera en `dist\WebAudit-Sec.exe`. El programa abre una ventana propia y solo inicia su servidor local en `127.0.0.1`.
